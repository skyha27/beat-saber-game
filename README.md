# Beat Saber Game

* 3D printed parts printed using BambuLab printer.

## Parts List

* MPU6050 3 Axis Accelerometer Gyroscope Module
* Mini Slide Switch
* [Powerboost 1000C](https://www.adafruit.com/product/2465)
* 2x Misc Adafruit Lipo 3.7V Batteries
* Wires
* ESP32
